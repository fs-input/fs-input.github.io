# PUA Custom Radical Legend
{: .fs-8 }

The Fengshui radical table contains 76 custom-made radical glyphs. Since they have no standard Unicode code points, they are placed in the Unicode Private Use Area (U+E000–F8FF) and rendered by the embedded `EUDC.ttf` font. In plain text these characters cannot convey their shape — AI crawlers and accessibility tools only see the raw code points. This table maps each code point to its key, co-key radicals, representative example characters, and a textual description, making the custom radicals machine-readable.

> **Note**: the first four columns (code / glyph / co-key radicals / example chars) are auto-extracted from the radical table and the 6775-char decomposition table — objective data. In the **Description** column, entries marked "(inferred · to be verified)" are preliminary guesses based on the shared shape of the example characters and **may be wrong**; others are "(to be filled by author)". Final naming is decided by the author. Glyphs require EUDC.ttf to render and may show as boxes otherwise.
