# Статистика и анализ кодов
{: .fs-8 }

Текущая таблица кодов содержит 308,453 различных знака и слова: 8,214 отдельных знаков, 189,571 двухзнаковое слово, 74,312 трёхзнаковых слов и 36,356 слов из четырёх и более знаков. Им соответствуют 390,046 записей кандидатов с кодами и 184,055 используемых групп кодов.

## Размер словаря и кодовое пространство

26 букв образуют кодовое пространство для кодов длиной от одной до четырёх клавиш. Для каждой длины существует 26ⁿ буквенных комбинаций. Позиции кандидатов позволяют нескольким знакам или словам использовать один код, но не увеличивают число различных буквенных кодов. По умолчанию для одноклавишных, двухклавишных и трёхклавишных кодов сохраняется по пять кандидатов, а для четырёхклавишных — десять. Полные коды отдельных знаков сохраняются обязательно. ## Общая оценка кодирования

Согласно приведённому анализу, метод ввода Фэншуй «форма-фонетика» обладает следующими заметными преимуществами:

- **Большой словарь**: включает 8,214 отдельных знаков и 300,239 слов, всего 308,453 различных знака и слова, и охватывает подавляющее большинство знаков и слов, необходимых для повседневного ввода.
- **Высокая степень использования коротких кодов**: для одноклавишных кодов она составляет 100 %, для двухклавишных — также 100 %. Для трёхклавишных кодов использование первой позиции кандидата составляет 98.27 %, а позиций со второй по пятую — 89.52 %. Пространство коротких кодов используется полноценно.
- **Приоритет частотных записей**: часто употребляемые знаки и слова получают преимущество.
- **Высокая эффективность нажатий**: минимальное число нажатий, взвешенное по частоте, составляет 2.66 для отдельных знаков и 2.95 для всех знаков и слов. Часто употребляемым знакам и словам назначены короткие коды.
- **Равномерное распределение клавиш**: 26 буквенных клавиш распределены по позициям кода достаточно равномерно. Основная зона клавиатуры (EDC—SDFG—HJKL—I) используется чаще всего, что соответствует эргономическому замыслу.
